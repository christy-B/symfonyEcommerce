Symfony E-Commerce — Boutique intelligente avec IA

# INTRODUCTION
Solution e-commerce développée avec Symfony offrant la gestion complète d’une boutique en ligne : 
authentification, produits, panier, commandes, paiements et notifications par email.
L’administration intègre une fonctionnalité innovante : génération automatique de descriptions produits grâce à l’intelligence artificielle.
#

# Modules
## Produits : CRUD, génération de description IA.
## Panier : gestion complète des articles.
## Commandes : suivi et historique.
## Paiement : intégration Stripe.
## Emails : confirmations de commande et d’inscription.
## Authentification : création de compte avec validation par email.
## Admin : interface EasyAdmin sécurisée.
## IA : génère une description automatique à partir du nom, sous-titre, catégorie, prix et statut du produit
#
